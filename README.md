# YouTube Clone

YouTube homepage clone built with HTML and CSS (Grid, Flexbox, media queries) while following a tutorial.

Built while following [HTML & CSS Full Course - Beginner to Pro](https://www.youtube.com/watch?v=G3e-cpL7ofc) to practice HTML and CSS.

## What I practiced

- CSS Grid
- Flexbox
- Positioning
- Media queries

## Running it

Open `index.html` in a browser.

**Live demo:** https://aranbhambra.github.io/youtube-clone/
